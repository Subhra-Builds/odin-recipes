# odin-recipes

## Introduction
This project is a basic recipe website built as part of my web development journey. It consists of a main index page that links out to a collection of individual recipe pages. 

While the site focuses purely on raw structure without any CSS styling for now, it serves as a foundational exercise to practice writing clean, semantic HTML from scratch. I plan to revisit this project later to style and enhance its layout using CSS.

## Skills Demonstrated
By completing this project, I will have demonstrated my ability to:
* Set up a standard HTML boilerplate (`<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`).
* Structure content semantically using headings (`<h1>` through `<h6>`) and paragraphs (`<p>`).
* Organize ingredients and step-by-step instructions using unordered (`<ul>`) and ordered (`<ol>`) lists.
* Create relative links (`<a>`) to connect multiple pages within a project directory.
* Embed images (`<img>`) with proper `src` paths and descriptive `alt` attributes.
* Manage project files and version control using Git and GitHub.
